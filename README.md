## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+) & `npm`
- [Java JDK](https://adoptium.net/) (v17+) & [Apache Maven](https://maven.apache.org/) (for Java/Kafka/CI-CD modules)
- [Docker & Docker Compose](https://www.docker.com/) (for Kafka & CI/CD pipeline experiments)
- [Git](https://git-scm.com/)

### Running Node / React Projects

Navigate into any frontend or full-stack directory and run:

```bash
npm install
npm run dev   # or npm start
```

### Running Java / Docker Projects

For backend systems such as `experiment-9-cicd-pipeline` or `kafka-reliability-system`:

```bash
docker-compose up -d
mvn clean install
```
